# ChimeraVox Demo

Forge a narrated video from a single photo and a script.

- **Ken Burns mode** (default): CPU-only pan/zoom + edge-tts — always works
- **Dry-run**: colored mock clips for pipeline testing
- **Full AI**: ZeroGPU Spaces (LTX / CogVideoX / Wan) with automatic Ken Burns fallback
